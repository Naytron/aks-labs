# Contributing

Keep each lab outcome-based and testable. A learner module must contain:

1. Before-you-begin state, prerequisites, timebox, and cost boundary.
2. An outcome and no more than one page of must-know facts.
3. A scenario, exact starting point, and progressively reduced guidance.
4. Checkpoints with expected evidence.
5. Measurable acceptance criteria mapped to automated or manual evidence.
6. One reversible break/fix exercise.
7. Three progressive hints.
8. Tips, lab shortcuts, production defaults, cleanup, next state, and a reference solution.

Do not add automatic Azure deployment to pull-request workflows. Pin external GitHub Actions to immutable commit SHAs. Update `.devcontainer/tools.env`, `docs/maintenance.md`, and tested Kubernetes versions together.
