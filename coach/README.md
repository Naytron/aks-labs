# Coach materials

Learners should not read this directory during the challenge.

## Delivery rules

- Validate all scenarios in the delivery region before class.
- Inject only one new unknown at a time until Day 5.
- Require evidence before hints or restore.
- Never inject against an untagged namespace/resource group.
- Stop an exercise when cost, quota, identity, or subscription scope is uncertain.

## Hint ladder

1. Restate the failed acceptance criterion.
2. Identify the control plane that should reconcile it.
3. Point to the first evidence source.
4. Narrow the resource.
5. Reveal a command category, not the answer.

See daily coach notes for timing and expected signatures.
