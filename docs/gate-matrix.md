# Daily gate evidence matrix

| Gate | Automated evidence | Manual evidence |
| --- | --- | --- |
| Prework | tools, Docker, providers, SKU/quota, tests, `kind`, Bicep/no-write | baseline remediation notes |
| Day 1 | local/Automatic workload, image metadata, Gateway, separate fault recovery, Automatic deletion | Automatic-vs-Standard table |
| Day 2 | network profile, Cilium, pools/taints, Gateway/route, persistence, resource inventory | IP worksheet, traffic trace, ADR |
| Day 3 | CSI mount, federated values, policy objects, allowed/denied traffic, Flux readiness | persona matrix, identity diagram, drift/prune record |
| Day 4 | metrics targets/query, HPA/KEDA/VPA ownership, node scale, Spot cleanup, restore row count, cost | SLO, drain timeline, upgrade/DR decisions |
| Day 5 | workload/Flux health, no placeholders/secrets, final inventory zero | three incident reports, capstone rubric, runbook, ADR, defense |

An automated pass never substitutes for a manual architecture decision. A manual artifact must name its evidence source and acceptance criterion.
